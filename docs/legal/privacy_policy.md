【運営者名】(以下「運営者」といいます)は、サービス「まちびん」(以下「本サービス」といいます)における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー(以下「本ポリシー」といいます)を定めます。

## 1. 事業者情報

| 項目 | 内容 |
| --- | --- |
| 運営者 | 【運営者名(個人の場合は氏名または屋号)】 |
| 所在地 | 【所在地(個人開発者の場合、開示等請求への対応方法とあわせて記載方法を専門家に確認)】 |

## 2. 取得する情報

本サービスが取得する情報は次のとおりです。**本名・生年月日・住所(番地)・電話番号・顔写真は取得しません。**

| 情報 | 取得方法 | 保管先 |
| --- | --- | --- |
| メールアドレス | GoogleまたはAppleアカウントでのログイン時に認証基盤(Clerk)が取得 | 認証基盤(Clerk)のみ。運営者のデータベースには保存しません |
| Google/Appleアカウントのプロフィール情報(氏名等) | ログイン時に認証基盤へ付随的に提供されることがあります | 認証基盤(Clerk)のみ。本サービスのプロフィールには使用しません |
| ニックネーム・アバター(選択式)・ひとこと自己紹介 | 利用者の入力 | 運営者のデータベース |
| 居住エリア(任意・市区町村まで) | 利用者の選択 | 運営者のデータベース |
| 投稿内容(場所名・位置情報・カテゴリ・コメント) | 利用者の投函 | 運営者のデータベース |
| 位置情報(現在地) | 端末の位置情報機能(利用者が許可した場合のみ) | 約150m四方に丸めた座標のみ保存(3章) |
| リアクション・訪問記録・通報内容 | 利用者の操作 | 運営者のデータベース |
| 年齢確認・利用規約への同意日時 | 初回設定時のチェック | 運営者のデータベース |
| プッシュ通知用の端末トークン | アプリの通知許可時 | 運営者のデータベース |
| IPアドレス・アクセスログ | 通信に伴い自動取得 | インフラ事業者(Cloudflare)。セキュリティ・障害調査目的に限定 |
| 障害・クラッシュ情報(端末機種・OS等) | アプリ・サーバーの障害発生時 | エラー監視サービス(Sentry)。個人を特定する項目は送信前に除去 |

### 取得しない情報(明示)

生年月日、本名、番地レベルの住所、電話番号、顔写真、**丸め処理前の正確な位置座標**、バックグラウンドでの位置情報、広告識別子(IDFA/AAID)、端末内の連絡先・写真。

## 3. 位置情報の取り扱い(重要)

本サービスは位置情報を扱うため、次の保護措置を講じています。

1. **投稿位置は約150m四方の区画の中心点に丸めて送信・保存します。** 丸める前の正確な座標は、端末の外へ送信されず、どこにも保存されません。
2. 現在地の取得は、**利用者が明示的に許可した場合のみ**、アプリの使用中に限り、その都度行います(継続的な追跡は行いません)。許可しない場合も、地図でピンを指定して投稿できます。
3. 交換相手に表示されるのは、丸められた位置・場所名・カテゴリ・コメント・(設定した場合)市区町村レベルの居住エリアのみです。**ニックネームを含め、投稿者個人を特定できる情報は相手に表示されません。**
4. 広告や行動ターゲティングの目的で位置情報を利用することはありません。

## 4. 利用目的

| 目的 | 対象情報 |
| --- | --- |
| 本サービスの提供(認証、スポットの交換・配達、場所帳、通知) | 2章の各情報 |
| 不正行為の防止・対応(スパム対策、通報対応、利用制限、処分逃れの再登録防止) | 投稿内容、通報内容、交換除外記録、アクセスログ |
| 障害対応・品質改善 | アクセスログ、クラッシュ情報、通知送信記録 |
| 法令に基づく対応 | 必要な範囲の情報 |

取得した情報を上記以外の目的(広告配信等)に利用することはありません。利用目的を変更する場合は、本ポリシーを改定し周知します。

## 5. 第三者提供

1. 運営者は、次の場合を除き、個人データを第三者に提供しません。**広告目的の第三者提供は行いません。**
   - 法令に基づく場合(捜査機関からの適法な照会等)
   - 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが困難な場合
   - 業務委託に伴う提供(6章)
2. 利用者間で表示される情報は3章3項に記載の範囲に限られます。

## 6. 業務委託先(外国にある第三者への提供を含む)

本サービスは、以下の外部サービスに業務を委託しています。いずれも所在国は**米国**です。運営者は、各社が個人データ保護のための相当措置を継続的に講じる体制(契約条項・SOC 2等の第三者認証)を有することを確認のうえ利用しています。

| 委託先 | 委託内容(取り扱う情報) |
| --- | --- |
| Clerk, Inc. | ログイン認証・アカウント管理(メールアドレス、Google/Apple連携情報) |
| Neon, Inc. | データベースの運用(2章のうち運営者データベース保管分) |
| Cloudflare, Inc. | サーバー・通信基盤・セキュリティ(IPアドレス、通信記録) |
| Expo(650 Industries, Inc.) | プッシュ通知の配信(通知用トークン。通知内容に個人情報・位置情報は含めません) |
| Functional Software, Inc.(Sentry) | 障害・クラッシュ情報の収集(個人を特定する項目は送信前に除去) |

**米国の個人情報保護制度について:** 米国には、日本の個人情報保護法に相当する包括的な連邦法はなく、州法および分野別の法令により保護が図られています。制度の詳細は個人情報保護委員会が公表する調査結果をご参照ください。委託先が講ずる措置の概要については、1章の窓口にお問い合わせいただければ遅滞なく回答します。

## 7. アプリからの情報送信(外部送信)

本サービスのアプリは、機能の提供のために、利用者の端末から次の外部事業者へ情報を送信します。

| 送信先 | 送信される情報 | 目的 |
| --- | --- | --- |
| Clerk(認証) | ログイン操作に伴う認証情報、端末・ブラウザ情報 | ログインの実行・セッション維持 |
| 運営者のサーバー(Cloudflare上) | アプリの操作に伴う2章の情報 | 本サービスの提供 |
| Expo(通知) | プッシュ通知用トークンの発行に必要な端末情報 | 通知の配信 |
| Sentry(障害監視) | クラッシュ・エラー情報(端末機種、OSバージョン等) | 障害の検知・修正 |

広告・行動分析を目的とした情報送信(トラッキング)は行いません。

## 8. 保存期間・退会時の取り扱い

### 8.1 退会時

アプリ内の退会手続により、データは次のとおり処理されます。

| 区分 | 対象 |
| --- | --- |
| 削除 | メールアドレス等の認証情報(Clerk上)、あなたの「もらった場所帳」、通知用トークン、通知送信記録 |
| 匿名化 | プロフィール(ニックネーム等を消去)、投稿したスポット(公開を終了し、投稿者との関連を切り離し) |
| 残置(匿名) | **すでに他の利用者へ届いたスポットの複製**は、投稿者を特定できない状態で受け取った相手の場所帳に残ります |
| 残置(不正対策) | **通報記録・交換除外の記録**は、処分逃れの再登録防止・通報対応の証跡のために退会後も保持します(個人を特定する項目は上記の匿名化により失われます) |

### 8.2 その他の保存期間

- 通知送信記録は90日、システム連携記録は30日で自動削除します。
- アクセスログの保持は短期間(最長30日)に限定します。
- 削除されたデータも、障害復旧用のバックアップ(復元履歴)から完全に消滅するまでに一定期間を要する場合があります。

## 9. 利用者の権利(開示等の請求)

1. 利用者は、プロフィール・投稿・場所帳をアプリ内でいつでも確認でき、プロフィールは随時変更できます。
2. 利用者は、1章の窓口を通じて、保有個人データの開示・訂正・利用停止・消去等を請求できます。ご本人確認のうえ、法令に従い遅滞なく対応します。
3. データの削除は、アプリ内の退会手続でも実現できます(8.1章)。

## 10. 年齢に関する取り扱い

1. **13歳未満の方は本サービスを利用できません。** 登録時に13歳以上であることの確認を行います(生年月日は取得しません)。
2. 未成年者(18歳未満)の方は、親権者など法定代理人の同意を得たうえでご利用ください。

## 11. 安全管理措置

- すべての通信をTLSにより暗号化しています。
- 認証情報(パスワード等)を運営者は保有せず、認証は専門事業者(Clerk)およびGoogle・Appleの認証基盤に委ねています。
- データベース等への接続情報は厳格に管理し、アクセスは業務上必要な範囲に限定しています。
- サーバーのログ・障害情報に、位置情報・コメント本文・認証情報等が含まれない仕組みを講じています。
- 委託先の選定時および定期的に、第三者認証の取得状況等を確認しています。

## 12. Cookie等・アクセス解析

- アプリに広告SDK・行動トラッキングは含まれません。
- ウェブサイト(本ポリシー等の掲載ページ)では、サイト運用に必要な範囲でインフラ事業者(Cloudflare)による通信記録が生成されます。
- アクセス状況の把握は、個人を特定しない集計値(リクエスト数等)により行います。

## 13. 本ポリシーの改定

本ポリシーを改定する場合は、本ページで公表し、重要な変更についてはアプリ内の表示等で周知します。改定後の本ポリシーは、本ページ掲載時から効力を生じます。
