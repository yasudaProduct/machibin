# ADR（Architecture Decision Records）

実装レベルの技術判断の記録（12 開発標準 §10.3）。設計書を改訂するほどではないライブラリ選定・実装方式・スパイク（SP-xx）の結果をここに残す。BD-xx級のプロダクト仕様の決定はdocs/README.md §2のBD表で管理する。

## テンプレート

```markdown
# ADR-NNN: <タイトル>

- 日付: YYYY-MM-DD
- ステータス: 提案 | 採用 | 廃止（廃止時は後継ADRを記載）

## 背景

なぜ判断が必要になったか。

## 決定

何を選んだか。

## 理由

比較した選択肢と決め手。

## 影響

関連する設計書・コード・SP-xx。
```
